# Class X Physics MCQ source review

The 18-page `Data/Class X/Physics_MCQs.pdf` exercise extract was compared with 119 questions in source order, from Units 10–20. One omitted Unit 10 question was restored and the two figure-dependent Unit 10 questions now include source crops. No answer key was supplied; this is not proof of coverage of the full textbook.

The printed source has apparent issues: Unit 13 question 13 duplicates “Convex glasses” and appears to offer no correct lens; Unit 14 question 10 duplicates equivalent options; Unit 19 question 10 has malformed isotope notation and no clear correct choice; Unit 20 question 11 may admit more than one true statement. The original options are retained rather than silently repaired. Review these before using them in an examination.
