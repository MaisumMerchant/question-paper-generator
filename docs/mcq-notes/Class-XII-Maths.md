# Class XII Mathematics MCQ review — in progress

The supplied `Data/Class XII/Math_MCQs.pdf` is an exercise-page extract, not the full textbook. The questions in Functions and Limits, Differentiation, Higher Order Derivatives and Applications, and Differentiation of Vector Functions were re-transcribed against the extract (review exercises 2–5, 56 questions). The remaining existing chapters have not yet been checked and should not be treated as verified. Further source questions remain to be transcribed.

Some printed questions are ambiguous or flawed: review exercise 2(iv) gives a relation but does not state what to find, and 2(xii) asks for a two-sided limit that does not exist among the given choices. Review exercise 3(xi) depends on the interval of x. Review exercise 4(ix) can depend on whether decreasing means strictly or non-strictly, and 4(x) has related stationary/critical terminology. These are retained as printed, without an answer key.
