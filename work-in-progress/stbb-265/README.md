# STBB Urdu Islamiat IX–X: transcription draft

Source: https://portal.stbb.edu.pk/ebooks/pdf_proxy.php?id=265

This is a work-in-progress transcription, not a production question bank. The linked scan is a combined Class IX–X Urdu textbook; the division of its contents between the classes has not been established. No Sindhi-language Islamiat material is included.

- 101 first-pass questions from 35 candidate exercise pages, with 1-based PDF page and printed page recorded on each item.
- Candidate PDF pages: 11, 17, 23, 29–30, 36–37, 42, 46, 50, 54, 58, 63, 68, 74, 77, 84, 88, 93, 100–101, 105, 113, 119, 121, 126, 129, 133, 137–138, 143–144, 148, 151, 155.
- These pages and their wording, Quranic text and diacritics, options, page completeness, and class allocation all require proofreading against the original. An apparent textbook error should be preserved and flagged, not silently corrected.
- The original option labels الف، ب، ج، د are represented by A, B, C, D in order. Five questions on PDF page 151 have three options in the source; no fourth has been invented.
- No answer key is included: the exercises do not mark correct answers, and independent answers have not yet been verified.
- Chapter names are provisional printed-page labels, not definitive chapter metadata.
- This folder is outside `Data/` so the app does not present an unreviewed draft as a completed bank. The old English-medium IX Islamiat PDF was not replaced. The scanned candidate extract is not yet committed.
